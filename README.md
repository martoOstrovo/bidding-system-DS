## React frontend

The app is in [`frontend`](frontend/README.md). With the backend running, start it
from the repository root:

```powershell
cd frontend
npm ci
npm run dev
```

Open http://localhost:5173. Rebuild/restart the updated gateway to enable login
and logout redirects to the frontend. The frontend README includes Docker setup
and validation commands.
